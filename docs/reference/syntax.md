# 脚本文法

对话脚本的完整文法说明，按解析规则组织。入门教程见[对话脚本](../tutorial/scripting.md)。文法的行为以 `DialogParser` 的实现为准。

## 文件与脚本 ID

脚本放在 `data/<命名空间>/dialog/` 下，扩展名 `.txt`，可以放在任意深度的子目录。脚本 ID 是文件路径相对 `dialog/` 去掉扩展名的部分：

| 文件路径 | 脚本 ID |
| --- | --- |
| `data/village/dialog/intro.txt` | `intro` |
| `data/village/dialog/chapter/one.txt` | `chapter/one` |

命名空间不参与脚本 ID。不同命名空间产生相同 ID 时，整个数据包加载失败。

## 行

```text
文件     ::= { 行 }
行       ::= 空行 | 注释行 | 分界线 | 动作行
注释行   ::= [空白] "#" 任意字符
```

空行与注释行不产生动作。行首的 `#` 可以用 `\#` 转义成正文。除 `\#` 与 `\$` 之外的转义组合没有特殊含义，按原样保留。

## 分界线

```text
分界线   ::= [空白] "---" [空白] 对话名称
```

`---` 之后去掉两端空白是对话名称。名称不能为空，不能包含空白或冒号，也不能与脚本 ID 或已有子对话重名。第一个分界线之前的动作组成默认对话，默认对话的名称与脚本 ID 相同。

## 动作行与条件

```text
动作行   ::= [空白] [条件] 动作
条件     ::= "(" 表达式 ")"
```

条件位于行首，括号按嵌套配对，表达式去掉两端空白后不能为空，条件之后必须紧跟一个动作。条件在动作开始时求值一次，结果为假就跳过整个动作。去掉条件后，行首是 `[` 时按命令动作解析，其余情况按对白动作解析。

## 命令动作

```text
命令动作 ::= "[" 命令序列 "]" [空白 选择器] [空白 行尾注释]
```

方括号按嵌套配对，命令内部可以出现方括号，例如 `[execute as @e[type=zombie] run say hi]`。右侧方括号之后只允许出现选择器与行尾注释。行尾注释从第一个未转义的 `#` 开始，方括号内部的 `#` 属于命令本身。

## 对白动作

```text
对白动作 ::= [人物 ":"] 正文 [空白 观众选择器] [点击命令]
点击命令 ::= "[" 命令序列 "]" [空白 选择器]
```

正文中第一个 `:` 用来分隔人物与正文，冒号没有转义形式，冒号之前的人物不能为空。正文先截断行尾注释（第一个未转义的 `#` 之后的部分），再识别点击命令、观众选择器：只有正文以配对的 `]` 结尾时，末尾的方括号才作为点击命令；找不到配对的 `[` 时，方括号保留为普通文本。

观众选择器是正文末尾一个前面带空白、以 `@` 开头且内部没有空白的词。同一行还有点击命令时，观众选择器写在点击命令之前，点击命令右侧的选择器属于点击命令：

```text
Alice: 都过来 @a[distance=..10] [goto next] @p
```

这行对白发送给 `@a[distance=..10]` 匹配到的玩家，点击后以 `@p` 执行 `goto next`。没有观众选择器时使用 `data/storyteller/settings.json` 中的 `defaultAudienceSelector`：

```json
{
  "defaultAudienceSelector": "@s"
}
```

数据包在自己包里放同名文件即可覆盖。以 `@` 开头但前面没有空白的词按普通文本处理，因此正文可以出现邮箱地址。

## 正文片段

```text
正文     ::= { 字面文本 | 颜色符号 | 内联命令 | 转义井号 | 转义美元符 }
颜色符号 ::= "&" 颜色代码
颜色代码 ::= "0".."9" | "a".."f" | "k".."o" | "r"
内联命令 ::= "$" 命令序列 "$"
```

颜色代码不区分大小写，改变后续文本的样式，未知的颜色代码按普通文本保留。`&` 没有转义形式。内联命令的两个 `$` 之间不能为空，渲染时执行命令序列并把输出拼接为文本；流程命令不能写进内联命令，`get` 可以。

## 命令序列与选择器

```text
命令序列 ::= [ "repeatable" ";" ] 命令 { ";" 命令 }
选择器   ::= "@" 非空白字符序列
```

命令之间用 `;` 分隔，每个命令去掉两端空白，禁止空命令；命令里的字面 `;` 写成 `\;`。选择器默认 `@s`，写出时以 `@` 开头，不能包含空白，可以带方括号。执行时用选择器查找实体，对每个匹配的实体执行整条命令序列；脚本命令对匹配到的玩家逐个生效，匹配到非玩家实体时命令报错。命令动作的选择器同时决定调试文本的发送对象；由 `wait` 拆分出的等待动作继承这个选择器。

`repeatable` 作为点击命令序列的第一条命令时，点击 token 可以反复使用；它只能出现在点击命令里，后面必须至少跟一条命令，写在独立命令动作里时脚本加载失败。

## wait

`wait` 是动作关键字，不是 Minecraft 命令。写在命令序列里，加载脚本时被拆成独立的等待动作：

- `wait`：永久等待；
- `wait 40`：等待 40 游戏刻，参数必须是非负整数。

拆分后的动作各自保留原条件，`wait` 之后写在同一条序列里的命令在等待结束后再等一个动作间隔继续。`wait` 不能出现在点击命令里。

## 脚本命令裸名

七个脚本命令写在命令序列里时可以裸写名字，执行前自动加上 `storyteller:` 前缀交给命令系统处理：`expect`、`check`、`update`、`get`、`goto`、`delete`、`return`。要执行原版同名命令时写全限定名，例如 `minecraft:return`。`wait` 是动作关键字，在加载阶段拆分，不经过命令系统。

## 后处理

解析器返回原始结果，`DialogScriptRegistry` 安装脚本表时按优先级执行两个处理步骤：

1. **截断与拆分**：命令序列里 `return` 之后的命令被截断（点击命令同样处理），`wait` 被拆成独立的等待动作；
2. **token 化**：命令动作与点击命令的「选择器与命令序列」注册到全局 token 表，动作只保留 token。token 由选择器、命令序列与 `repeatable` 标记计算 SHA-256 得到，取前 32 个十六进制字符；内容完全相同的命令调用得到相同 token。

选择器在解析动作行时解析成 `ParsedSelector`，语法错误在脚本装载阶段报告；没有写观众选择器的对白动作使用解析器构造参数提供的默认值，该默认值来自 `settings.json` 的 `defaultAudienceSelector`。

## 解析错误

任何文法错误都会让整个数据包加载失败，旧脚本继续工作。错误信息带行号。常见错误：

| 错误 | 原因 |
| --- | --- |
| `Divider is missing a dialog name` | 分界线后面没有名称 |
| `Invalid dialog name` | 对话名称包含空白或冒号 |
| `Duplicate dialog name` | 名称与脚本 ID 或已有子对话重复 |
| `Condition is missing a closing parenthesis` | 条件缺少右括号 |
| `Condition is empty` | 括号内表达式为空 |
| `Condition is not followed by an action` | 条件后面没有动作 |
| `Command action is missing a closing bracket` | 命令动作缺少右方括号 |
| `Unexpected content after command action` | 方括号后出现选择器与注释之外的内容 |
| `Invalid selector` | 选择器格式错误 |
| `Speaker is empty` | 冒号之前的人物名称为空 |
| `Inline command is missing a closing $` | 内联命令缺少结束的 `$` |
| `Flow command cannot be used in an inline command` | 流程命令写进了内联命令 |
| `Command is empty` | 命令序列里出现空的命令 |
| `Invalid wait timeout` | `wait` 的参数不是非负整数 |
| `wait cannot be used in a click command` | `wait` 写进了点击命令 |

脚本命令的参数错误与引用检查在加载阶段报告，完整清单见 `stc lint` 的诊断输出（[工具链](./toolchain.md)）。
