# 触发实体

三个不显示外观的触发实体，用原版 `/summon` 加 NBT 生成，把地图里的行为接进对话系统。教程见[触发实体](../tutorial/triggers.md)。

## 共同行为

- 事件发生时以触发玩家为执行者运行命令，权限为管理员级别；
- 命令与对话脚本的写法一致：裸写的流程命令（`goto`、`expect`、`update`、`get`、`check`、`delete`、`return`、`wait`）自动加上 `storyteller:` 前缀；
- 命令为空字符串时不执行任何命令；
- 旁观玩家不触发；
- 实体不显示外观，保存与加载由游戏本体处理。

## collision_trigger

玩家进入或离开区域时运行命令。

| NBT 字段 | 类型 | 含义 |
| --- | --- | --- |
| `x1`、`y1`、`z1` | 小数 | 区域角点 A 相对实体位置的偏移 |
| `x2`、`y2`、`z2` | 小数 | 区域角点 B 相对实体位置的偏移 |
| `enter` | 字符串 | 玩家进入区域时运行的命令 |
| `leave` | 字符串 | 玩家离开区域时运行的命令 |

两个角点的先后顺序任意，区域取两者的包围盒。实体每个游戏刻用玩家的包围盒与区域求交：

- 非旁观玩家从区域外进入时，运行一次 `enter`；
- 从区域内离开时，运行一次 `leave`。

区域内的玩家记录只保存在内存里，不进存档：

- 实体所在区块重新加载后，仍在区域里的玩家会再次收到一次 `enter`；
- 玩家断线时不运行 `leave`，重新加入后仍在区域里会再次收到一次 `enter`。

## interact_trigger

玩家与实体交互或攻击实体时运行命令。

| NBT 字段 | 类型 | 含义 |
| --- | --- | --- |
| `runInteract` | 字符串 | 玩家右键实体时运行的命令 |
| `runAttack` | 字符串 | 玩家攻击实体时运行的命令 |

交互与攻击都会阻止原版处理：实体不受伤，右键不会触发对其他实物的交互。交互距离按原版规则检查。实体有一个 1×1 的碰撞判定，一直可以被右键或攻击命中。

## block_trigger

玩家在实体所在的方块位置放置或破坏方块时运行命令。

| NBT 字段 | 类型 | 含义 |
| --- | --- | --- |
| `runPlace` | 字符串 | 方块被放置时运行的命令 |
| `runBreak` | 字符串 | 方块被破坏时运行的命令 |

方块位置取实体的 `blockPosition()`，实体生成在哪个方块里就监听哪个方块：

- 破坏事件在方块移除之后运行 `runBreak`；
- 放置事件只在玩家手持方块物品、方块类型确实发生变化且新方块对应该物品时触发，并在服务器任务队列中运行 `runPlace`。

## 调试支持

`/st debug` 切换调试状态时，加载中的触发实体收到同步，客户端为它们绘制线框：

| 实体 | 线框 |
| --- | --- |
| `collision_trigger` | 区域包围盒 |
| `interact_trigger` | 实体碰撞判定 |
| `block_trigger` | 所在方块位置 |

三种线框使用不同颜色。`collision_trigger` 与 `block_trigger` 只在调试状态下可被选中；`interact_trigger` 始终可以。手持调试棒与触发实体交互时，实体属性发到聊天栏；`block_trigger` 也支持直接对它所在的方块使用调试棒查看属性。
